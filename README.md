# Next.js Application 🚀

Modern, responsive web application bootstrapped with [Next.js](https://nextjs.org) and React.

## Features
- **App Router Architecture**: Leverage Next.js nested layouts and Server Components.
- **Geist Typography**: Optimized font rendering via `next/font`.
- **Fast Refresh**: Instant feedback during local development.

## Getting Started

### Prerequisites
- Node.js >= 18.x
- npm, pnpm, or yarn

### Installation & Run

```bash
# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.

## Production Build

```bash
npm run build
npm run start
```
